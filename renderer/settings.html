CLAUDE CODE

CHECKING…

Writes 6 hooks into ~/.claude/settings.json (a backup is saved next to it): working → status light + thinking face · finished → happy jump · needs you → alert · asks a question → the options appear on the cat. Hooks also capture which terminal tab asked, so the cat can jump you (and your answer) back to it.

CODEX CLI

CHECKING…

Adds a notify hook to ~/.codex/config.toml (backup saved). Codex fires it when a turn completes → happy jump + "CODEX DONE!". Codex doesn't expose working/question events to external hooks, so it's done-only. Note: the desktop Codex app and any background CLI sessions share this config — every completed turn lands in INBOX with the assistant's last words, so you can always tell which Codex spoke.

BACKGROUND AUTOMATION

Sessions running in a terminal you can see (iTerm, Terminal) always celebrate. Everything else — batch codex exec runs, scheduled jobs, app-servers — stays quiet and leaves a trail in INBOX instead.

QUESTIONS

First use will trigger one-time macOS prompts to allow controlling Terminal/iTerm2 and System Events. Embedded terminals (VS Code, Cursor) can't be tab-targeted — the cat then shows "WINDOW NOT FOUND" and you answer manually. Permission prompts (not questions) are always focus-only.
